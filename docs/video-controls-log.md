# Управление видеокружочками — 11 ноября 2026

По двум скриншотам Samsung Browser подтверждено наложение штатной белой кнопки плеера и добавленной бордовой кнопки. При воспроизведении бордовая пауза оставалась поверх кадра.

До исправления добавлена проверка: во всех восьми вхождениях видеокружочков должны быть только штатные controls, без кнопок circle-play. Проверка не прошла на наличии бордовой кнопки.

Из генератора удалена дополнительная кнопка вместе с обёрткой, из JS удалены её обработчики, из CSS — все её стили. Сохранены штатное управление видео, круглая форма и даты. Проверка охватывает Дневник и отдельные страницы роликов. Оба теста мобильной стрелки и холста включены в npm test вместе с проверками сайта.

Дополнительно по следующему сообщению пользователя заголовок Отзывов изменён на «Слова, которые остаются после Вас», слова «остаются после Вас» оставлены курсивом.
