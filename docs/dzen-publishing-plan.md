# Автоматическое наполнение из Дзена

Сейчас не подключено. Проверка 11.11.2026 не подтвердила публичного поддерживаемого API или штатной полной RSS-выгрузки авторского канала в направлении Дзен → сторонний сайт. Описываемые в сети RSS-интеграции сайт → Дзен имеют обратное направление; их нельзя считать решением этой задачи.

Возможная реализация для текущего статического сайта: отдельный импортёр по расписанию получает новые публичные публикации разрешённого канала, сохраняет текст, дату, изображения и видео в локальный каталог, присваивает постоянный идентификатор, создаёт самостоятельную страницу сайта, проверяет ссылки и запускает сборку/публикацию GitHub Pages. Повторный запуск обновляет существующую статью вместо дублирования. Обложки и файлы хранятся на сайте, внешняя площадка не нужна для просмотра. Пропавшую или неполную публикацию нельзя автоматически затирать: ошибка должна уходить владельцу, а последняя исправная версия оставаться на сайте. Импорт HTML нужно очищать от скриптов, трекеров и чужих встраиваний.

Ограничение: импортёр публичных страниц зависит от разметки, доступности и ограничений Дзена. Без подтверждённого штатного интерфейса нельзя обещать бессрочную работу без обслуживания. Ни платный посредник, ни неофициальный «API» этого ограничения не устраняют. До разработки нужен пробный перенос нескольких полных статей и вложений с конкретного канала.

Что получить от Алёны:
- точный адрес канала и подтверждение прав на повторную публикацию текстов и медиа;
- редакторский доступ, если Дзен позволяет его выдать для нужной операции; пароль и коды входа передавать не нужно;
- несколько полных исходных статей с оригинальными изображениями/видео для проверки импорта;
- решение, как обрабатывать правки и удаления, рубрики и задержку публикации;
- доступ владельца к репозиторию и учётной записи/серверу, где будет работать расписание; секреты — в хранилище секретов, не в коде.

Если приоритет — минимальная зависимость от разработчика, наиболее предсказуемый вариант — простая CMS с визуальным редактором как основной источник контента. Алёна публикует один раз через привычный редактор; сайт получает готовые самостоятельные статьи. Передачу в Дзен подключают отдельно только после проверки доступного для её канала штатного способа. Посетителям сайта технический процесс не показывается.
