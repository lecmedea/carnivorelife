# Дневник Хищницы

Авторский сайт Алёны: https://lecmedea.github.io/carnivorelife/

Статический HTML/CSS/JavaScript, без сборки и npm-зависимостей. Запуск: `python3 -m http.server 8873` в этой папке. Публикация: GitHub Pages → Deploy from a branch → main → / (root).

## Дизайн и поведение
- Авторский SVG-знак: капля, два клыка и улыбка.
- Пять фотографий обработаны встроенным imagegen, со сохранением личности в промптах; улучшено освещение, удалены старые текстовые наложения. Студийный натюрморт создан отдельно. AI-обработка может немного изменить детали исходной фотографии.
- Фото оформлены бумажными карточками с полупрозрачной лентой и тенями.
- Оригинальная стилизованная 2D-физика: пружинная поверхность, гравитация, капли с бликами, реакция на скорость скролла, отскоки от прямоугольных границ карточек, исчезающие потёки. Это визуальная модель, не полноценная CFD/3D-симуляция жидкости; повёрнутые карточки используют bounding box.
- Эффект отключается кнопкой, учитывает reduced motion, останавливается в скрытой вкладке и после затухания. Холст пропускает клики.
- Пасхалка: сердечко в подвале открывает личную записку. Escape закрывает окно.
- Тексты и контакты основаны на Taplink и предоставленном закреплённом посте. Закрытые публикации MAX не читались. Личные результаты отмечены как личный опыт. Медицинские обещания, долгие голодания и заявления об излечении не перенесены.
- Формы сбора данных и аналитика не подключены. Шрифт Golos Text загружается из Google Fonts с системным fallback.
